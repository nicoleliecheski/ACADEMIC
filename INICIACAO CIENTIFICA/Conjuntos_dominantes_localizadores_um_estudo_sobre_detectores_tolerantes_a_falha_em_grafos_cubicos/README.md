# Conjuntos dominantes localizadores: Um estudo sobre detectores tolerantes a falhas em grafos cúbicos
Esse repositório se destina a armazenar a implementação na linguagem C++ dos algoritmos desenvolvidos para o projeto de iniciação científica mencionado no título, além de armazenar também recursos de teste, na forma de arquivos de grafos no formato g6.
